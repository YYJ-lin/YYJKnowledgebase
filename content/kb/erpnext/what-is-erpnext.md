先说一句最直白的：**ERPNext 是一套免费开源的"公司管理系统"**，把销售、采购、库存、财务、人事这些事，从散落在 Excel 和微信里，收进一个系统。

你可以把它理解成"给公司用的记账本 + 仓库本 + 客户档案"，而且这几本账是**互相打通**的：卖出一单，库存自动减，应收账款自动生成，不用再手工抄一遍。

## 一、它到底解决什么问题

很多小公司的现状是这样的：

- 客户名单在销售自己的微信里；
- 订单一单一单记在 Excel；
- 库存在另一个人脑子（或另一张表）里；
- 月底财务追着要数据，凑半天还对不上。

上 ERP 本质上就是把这几件事连起来：**一次录入，各处自动更新**。

具体点说，在 ERPNext 里做一张销售订单，会发生这些事：

1. 库存里扣掉对应数量（不够会提醒你）；
2. 自动生成一张发货单；
3. 自动生成应收款，跟着进财务账；
4. 客户档案里能看到他买过什么、欠多少钱。

这些动作不需要人再重复录一遍 —— 这就是它比 Excel 强的地方。

## 二、"开源免费"是什么意思，不等于不花钱

这是新手最容易误解的地方，我说清楚：

- **软件本身免费**：代码公开，可以自己下载、自己部署，不收授权费（不像很多 ERP 按人头收费）；
- **但服务器要花钱**：你得有一台云服务器，或者至少一台长期开着的电脑；
- **实施要花时间**：装软件不难，难的是"你的业务流程怎么塞进系统里"，这部分要么自己啃，要么请人做；
- **二次开发要花钱**：想要的功能它没有，就得改代码。

所以我一般会说：**ERPNext 省的是软件授权费，不省落地的人力成本。** 预算要按"服务器 + 人"来算，不是按"软件"来算。

## 三、它有哪些模块

按常见说法，一辆"完整"的 ERP 大概包含这些：

| 模块        | 干什么                      |
| ----------- | --------------------------- |
| 销售 / CRM  | 客户、报价、订单、跟进记录  |
| 采购        | 供应商、采购单、到货        |
| 库存        | 出入库、调拨、盘点          |
| 财务        | 应收应付、总账、报表        |
| 制造        | BOM、生产计划（制造业才用） |
| 项目        | 项目、任务、工时            |
| 人事        | 员工、考勤、薪资            |
| 网站 / 电商 | 官网、商品展示（可选）      |

ERPNext 的好处是把这些都做在一个系统里，不用买五六个软件再想办法打通。

> [!tip] 别一上来全开
> 模块是"可以只装一部分"的。小公司通常先跑「销售 + 采购 + 库存」，财务报表能出来之后再碰人力、制造。一次性全上，大概率用不起来。

## 四、适合谁，不适合谁

**比较适合：**

- 有实物流转的贸易、批发、零售、小型制造；
- 现在靠 Excel + 微信管业务，数据老对不上；
- 有人愿意花时间把流程理一遍（这条最关键）。

**不太适合：**

- 规模还很小、业务也单一的门店（比如就卖几样固定商品、一个人管进销存）暂时用不上 —— 先把表格和账理顺更划算，等单量上来、或者要同时对接线上线下几个渠道时再考虑；
- 想"装上就自动变规范"的 —— 系统不会替你决定流程；
- 完全没有懂电脑的人、又不想花钱请实施的 —— 后面维护会很难。

## 五、我为什么会去碰它

最早不是我自己要用，是朋友找我。

他做批发，公司不大，客户和订单一直靠 Excel 加微信记。问题不在于"记不下来"，而在于"记得不齐"：销售改过的价格，财务那边不知道；仓库发出去的货，跟单子上的对不上；月底一核对，就得加班好几天。

他也想过买现成的 ERP，问了几家，报价按人数算，一年下来不便宜；功能倒是齐全，可里面一大半他用不上。

我当时的想法很简单：先把他最头疼的三件事——客户、订单、库存——放进同一个系统里，别的以后再说。ERPNext 免费开源、能装在自己的服务器上、要改也改得动，正好符合这个前提。

真正上手才发现，难的不是软件，是"把他脑子里那套流程讲清楚"。这件事我后面会单独写一篇。

后来陆陆续续又帮几个做贸易的朋友搭过，踩的坑都差不多：系统装得起来，但用不起来。

## 六、新手开始前要知道的三件事

1. **先画流程，再装软件**：拿张纸把"客户下单 → 备货 → 发货 → 收款"画出来，比装软件重要得多；
2. **数据先清洗**：客户名单、商品清单整理成表格，导入才不痛苦；
3. **给自己留时间**：第一次上手，先只跑一条业务线，跑顺了再扩。

## 七、最后

ERPNext 不是"高级版 Excel"，它是一套**要求你先想清楚流程**的系统。想清楚了，它非常好用；没想清楚，装完只会多一个没人用的系统。
