这一页说明本站怎么处理访问数据。内容很短，因为确实没什么可收集的。

## 本站不做什么

- 没有账号系统，不需要注册或登录
- 没有埋点统计脚本（没有 Google Analytics、没有 Umami、没有可见计数器）
- 没有 Cookie，除了下面提到的主题偏好
- 没有第三方广告

## 本站会存什么

- **主题偏好**：在浏览器本地存一个 `theme` 值（亮色 / 暗色），只存在你自己的浏览器里，不会上传。
- **搜索**：搜索完全在浏览器里跑，索引文件由本站静态提供，你输入的词不会发给任何服务器。

## 谁还能看到访问记录

本站托管在 GitHub Pages。按 GitHub 的政策，服务器可能记录基础访问日志（IP、UA 等）用于安全和运营，这部分不在本站控制范围内，详见 [GitHub 隐私声明](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement)。

## 外部链接

文章里会有指向外部站点的链接，那些站点有自己的隐私政策，本站不对其负责。
